# Project Status

Date: 2026-05-25

## Current Stage

Meridian is operational as a self-hosted OCI Network Monitor with Terraform provisioning, Ansible VM configuration,
a FastAPI backend, a buildable dashboard artifact, async regional collection, topology, route analysis, security posture,
deployment version metadata, and browser E2E coverage.

## Implemented

### Infrastructure

- Terraform baseline: optional workload compartment, VCN, subnet, internet gateway, optional NAT gateway, route table, security lists, compute instance, optional IAM dynamic group/policy, and optional Object Storage action archive.
- Ansible bootstrap: Nginx, systemd service, environment configuration, persistent snapshot directory, frontend artifact publishing, and version metadata publishing.
- Instance principal authentication for production; OCI config-file profile for development.
- No-cache Nginx handling for the dashboard shell and `version.json`.

### Backend

- FastAPI with uvicorn on `127.0.0.1:8080`, proxied through Nginx on port 80.
- Health, readiness, and deployment metadata endpoints: `/healthz`, `/readyz`, `/api/version`.
- OCI runtime preflight checks through `/api/preflight`.
- Region scope endpoints: available regions, active regions, and compartments.
- Full network inventory: VCNs, subnets, gateways, route tables, security lists, and NSGs.
- Route issue analysis: blackhole targets, duplicate default routes, and invalid entity references.
- Topology graph derived from live inventory relationships.
- Security posture checks across Security Lists and NSGs.
- Security action history and workflow filtering support.
- Async per-region collection pipeline with `ThreadPoolExecutor`.
- In-memory snapshot cache with configurable TTL.
- Persistent on-disk snapshot cache that survives restarts.
- Per-region collection status: `collecting`, `ready`, `ready_with_warnings`, `no_resources`, and `failed`.
- OCI client factory abstraction.
- 45 backend tests covering routers, services, exports, security actions, and inventory behavior.

### Dashboard

- Buildable dashboard artifact generated by `make frontend-build` from `oci_network_monitor_dashboard_v2.html`.
- Build metadata injected into `frontend/dist/index.html` and `frontend/dist/version.json`.
- Deployment badge showing the current frontend/backend revision state.
- Per-region collection status panel with spinner, duration, resource counts, and relative timestamps.
- Async polling with exponential backoff from 3 to 15 seconds.
- Selected-region coverage view to avoid noisy global coverage panels.
- Saved region views in the Regions menu.
- Interactive topology graph with overview, layer, VCN focus, and quick filters.
- Security posture panel with workflow filter, risky rule listings, action history, and OCI Console links.
- Route issue analysis panel.
- Inventory tables for VCNs, subnets, gateways, route tables, security lists, and NSGs.
- Region selector and compartment filter.
- OCI preflight access validation in the topbar.
- Demo fallback data when `MERIDIAN_ENABLE_LIVE_OCI=false` or when `/demodata` is used intentionally.
- 5 dashboard browser E2E tests.

## Not Yet Implemented

See [docs/module-map.md](docs/module-map.md) for the full planned feature list.

Key planned areas:

- VCN Flow Logs viewer.
- OCI Audit change feed.
- Metrics: gateway metrics, VNIC top consumers, inter-region latency.
- Advanced modules: DRG route inspector, OKE network health, load balancer health, private DNS, FastConnect/VPN.
- Intelligence layer: GenAI alarm explanation and natural language flow log query.
- Operations: exportable reports, OCI Notifications, Slack/Teams webhooks.
- Production hardening: HTTPS, remote Terraform state, private access pattern, containerized deployment, Meridian self-monitoring.
